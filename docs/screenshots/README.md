## Tips for screenshots

- Use a 1440×900 or 1280×800 browser window for consistent sizing
- Ensure the Bitbucket UI is fully loaded before capturing
- Use real (but redacted) example data if possible — it makes documentation more compelling
- Capture at 2x (Retina) resolution if available; the `index.html` placeholder comments show expected dimensions
