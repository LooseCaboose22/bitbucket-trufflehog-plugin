TruffleHog Secret Scanner

Bitbucket Data Center Plugin — Project Overview

This email provides a brief overview of the TruffleHog Secret Scanner plugin for Bitbucket Data Center. The plugin automatically detects leaked secrets (API keys, passwords, and credentials) committed to source code repositories and alerts the relevant teams.

What it does

✅ Scans every push in real time using TruffleHog v3 (700+ credential detectors)
✅ Runs scheduled full scans of all repositories on a configurable schedule
✅ Blocks, warns, or silently monitors based on branch and mode configuration
✅ Sends alerts to email, Microsoft Teams, and Slack
✅ Provides dashboards at system, project, and repository level
✅ Maintains a remediation workflow with audit trail

Feature Summary by Version

Version Capability
v1.0 Core secret detection, findings dashboard, remediation workflow, post-receive scanning
v1.1 Direct SMTP email, Teams/Slack webhooks, immediate & daily digest notifications
v1.2 Push result modes (Block/Warn/Silent), branch patterns, excluded pushers, scan size limits
v1.3 Enhanced metrics dashboard: scan outcomes chart, top detectors/repos, CSV export
v1.4 Custom regex detectors, warn-only detector classification, audit log
v1.5 Data Center per-node binary paths, proxy settings (HTTP/HTTPS/SSL cert), config export/import

Business Value

🔒 Prevent credential exposure — catch secrets before they reach shared/public branches and before rotation is needed
📊 Full audit visibility — every finding, remediation, and configuration change is logged and searchable
⚖️ Compliance support — demonstrates active controls for secret management audits (SOC 2, ISO 27001, PCI-DSS)
🔐 Developer-friendly — warnings on non-critical branches, immediate blocking only on protected branches
🔌 Existing infrastructure — built on Bitbucket's AO/OSGi framework; no external services required
